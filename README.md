# mcp-01-basics

This is first repo in the process of exploring mcp

Model Context Protocol (MCP) is a protocol for building and deploying AI models. It provides a standard way to define, train, and deploy AI models, making it easier for developers to create and share AI models.
https://modelcontextprotocol.io/docs/develop/build-server

mcp server hub
https://mcpserverhub.com/

setup pythoh

create a virtual environment

```bash
python -m venv mcp-venv
```

activate the virtual environment

```bash# On Windows
mcp-venv\Scripts\activate
# On macOS/Linux
source mcp-venv/bin/activate
```

install mcp server

```bash
pip install mcp-server
```

pip install -r requirements.txt

run mcp server

```bash
python server.py
```
